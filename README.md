# Financial Performance & Forecast Analytics

> **Synthetic portfolio project.** No confidential employer or client data is used.

## Portfolio story
Connect P&L performance, budget control and forward-looking forecasts in one executive decision view.

## Dashboard identity — Executive Finance
**Palette:** Navy #0F172A · Emerald #10B981 · Cyan #06B6D4 · Gold #F59E0B · Red #EF4444

The report uses a consistent typography system, rounded KPI cards, clear status indicators, rich tooltips, slicers, cross-filtering and drill-through. Color is used semantically rather than decoratively so positive, warning and negative states remain easy to read.

## KPI layer
- Revenue
- Gross Profit
- Operating Profit
- Gross Margin %
- Budget Variance %
- Forecast Accuracy %

## Report pages
1. **Financial Executive Summary**
2. **Revenue & Margin**
3. **Cost & Budget Analysis**
4. **Forecast & Scenario Outlook**

## Signature visuals
- Actual vs budget monthly timeline
- P&L waterfall
- Revenue/margin combo chart
- Cost composition stacked bars
- Business-unit performance matrix
- Forecast fan/scenario trend

## Interaction design
- Global period and business-dimension slicers
- Cross-highlighting between related visuals
- Report-page tooltips with contextual KPIs
- Drill-through from summary to detailed entity views
- Reset-filter affordance and selected-filter summary
- Conditional KPI badges for positive / watch / critical states
- Accessible labels and sufficient contrast; color is never the only status signal

## Technology
Power BI · SQL · DAX · Power Query · Python

## Build status
Dashboard visual system, report structure, BRD, starter SQL and DAX are in place. Synthetic data/model and production-ready report source are the next implementation layer.
