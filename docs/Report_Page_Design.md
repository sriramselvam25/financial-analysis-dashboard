# Report Page Design — Executive Finance

## 1 Financial Executive Summary
KPI ribbon: Revenue, Gross Profit, Operating Profit, Gross Margin, Budget Variance, Forecast Accuracy. Main canvas: Actual vs Budget trend, P&L waterfall, business-unit contribution and executive exception strip.

## 2 Revenue & Margin
Revenue/margin combo timeline, business-unit scatter, YoY growth ranking and monthly variance heatmap. Tooltips expose actual, prior year, budget and variance.

## 3 Cost & Budget Analysis
COGS/OpEx composition, budget variance waterfall, cost ratio trends and business-unit variance matrix. Negative exceptions carry icon + label as well as red status.

## 4 Forecast & Scenario Outlook
Actual vs Forecast timeline, forecast error distribution, scenario cards and forward outlook panel. Use confidence-style visual bands only when explicitly supported by generated scenario data.
